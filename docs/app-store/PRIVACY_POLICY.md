# Conn 隐私政策

最后更新：2026-08-05

Conn 是一款本地 SSH 服务器运维工具。我们不要求注册账号，也不运营 Conn 云服务。

## 我们处理的数据

- 你添加的主机配置、脚本、操作记录和密钥元数据保存在你的设备上。
- 私钥保存在 Apple Keychain 中；Conn 不会把私钥或主机配置上传到 Conn 服务器。
- 监控数据只在应用使用期间用于展示，不提供后台告警推送。
- Conn 不使用广告、跨 App 跟踪或第三方分析 SDK。

## 网络连接

Conn 仅连接你主动添加的 SSH 主机以及你在应用中明确配置的目标。远程命令、文件和 Docker 操作由你发起并承担相应风险。

## 应用锁

如果你启用应用锁，Conn 会使用设备密码或 Face ID/Touch ID 在本机验证身份。认证结果不会离开设备。

## 联系与更新

如需报告隐私问题，请通过项目仓库提交 issue。我们会在本页更新政策变更，并在应用发布说明中提示重大变化。
