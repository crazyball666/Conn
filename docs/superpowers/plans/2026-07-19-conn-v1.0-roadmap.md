## 硬约束（红线，任何 Phase 不得违反）

来自技术实现方案文首约束框 + PRD §4.1：

1. 纯客户端，**无任何自建服务端**、无账号体系、**零遥测**
2. **不做告警推送**（BGAppRefresh 本地通知除外，且需在 UI 内明示不保证实时）
3. 凭据只存本机 Keychain / Secure Enclave，**密文绝不入 SQLite**
4. 同步仅走用户自己的 iCloud，端到端加密
5. AI 走 BYOK，Key 仅存 Keychain，App 直连用户所配端点
6. 商业模式 = 免费 + 一次性买断（StoreKit 2 非消耗型），**绝不订阅**
7. 网络请求白名单：SSH 目标主机 / iCloud / 用户所配 AI 端点。**其余一律禁止**（CI 加 URL 字面量扫描）
8. 禁止引入任何分析/崩溃上报 SDK
