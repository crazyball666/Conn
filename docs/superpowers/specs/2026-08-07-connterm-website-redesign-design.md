# ConnTerm 官网 AB 结合重设计

日期：2026-08-07  
状态：用户已确认采用 A「产品截图主导」与 B「大字品牌叙事」结合方案

## 目标

重写 ConnTerm 官网首页，使用户在首屏就能理解它是一款面向 iPhone 的 SSH 服务器运维工具，并通过真实 App 截图快速确认产品能力。首页只承担产品介绍与转化，不再承担隐私政策说明。

独立的 `/privacy/` 页面继续保留，供 App Store Connect 填写公开 HTTPS 隐私政策 URL；官网首页的导航、正文、FAQ 和页脚都不展示隐私政策、隐私卖点或隐私链接。

## 视觉方向

采用“Editorial Product Story”方向：

- 直接复用 App 深色设计令牌：`#0A0C14` 页面底色、`#141826` 卡片、`#1A1F33`
  浮层、`#1F2437` 描边、`#EDEFF7` 主文字、`#8E95AC` 次文字；主操作色以
  `SettingsStore` 启动默认的 `AppAccent.purple` 为准（SwiftUI 深色系统紫约
  `#BF5AF2`），`#8B93FF` 只作为终端光标与辅助冷紫；状态绿 `#32D74B`、黄
  `#FFD60A`、红 `#FF5C5C` 只用于真实状态，不作为装饰；
- 首屏使用大字号编辑式标题建立品牌记忆，右侧以真实服务器列表界面作为主视觉；
- 后续章节使用真实 App 截图与短文交替排版，形成从观察到执行的产品故事；
- 去掉荧光黄、背景网格、假终端数据、概念控制台和同质化功能卡片；
- 页面不使用外部字体、图片 CDN 或分析脚本；标题使用本机 `Avenir Next` / `SF Pro Display` / 中文系统字体组合；
- 动效只用于首屏入场、章节淡入和截图轻微位移，并尊重 `prefers-reduced-motion`。

## 首页信息架构

### 1. 顶部导航

- ConnTerm 品牌；
- “产品能力”“产品画面”“支持”锚点；
- 中英文切换；
- App Store 状态按钮。没有正式产品 URL 时显示不可点击的“即将上线 / Coming soon”。

### 2. Hero

- 中文主标题：“你的服务器，不必等到回到电脑前。”
- 英文主标题：“Your servers shouldn’t have to wait for your laptop.”
- 副标题只解释产品：SSH 终端、主机监控、Docker、脚本和远程文件均可在 iPhone 上完成；
- 主视觉使用真实服务器列表截图，并通过 CSS 设备框与层叠状态卡增强空间感；
- 只保留 App Store 状态与“探索功能”两个动作，不出现隐私按钮或隐私文案。

### 3. 产品能力总览

用一条紧凑的能力索引呈现 `SSH / MONITOR / TERMINAL / DOCKER / SCRIPTS / FILES`，避免六张重复卡片。

### 4. 产品故事章节

按真实使用顺序展示：

1. 主机总览与详情：“所有主机，一屏掌握。”展示服务器列表与主机详情；
2. 多会话终端：“真正为触屏设计的终端。”展示终端输出和快捷键；
3. Docker 运维：“容器管理，不必打开电脑。”展示容器列表；
4. 批量脚本：“一次脚本，多台主机。”展示脚本执行页；
5. 远程文件：“远程文件，随时处理。”展示文件管理页。

每个章节只包含一个明确标题、一段两行以内说明和 2–3 个实际能力标签。截图使用 `docs/app-store/screenshots/raw/{zh,en}/` 的现有真实界面资产；部署站点会复制到 `docs/website/assets/product/{zh,en}/`，中英文切换同步切换截图。

### 5. 收尾转化

- 标题：“服务器在远方，控制力在手边。”
- App Store 状态按钮；
- 支持链接固定为 `https://github.com/crazyball666/Conn/issues`。

### 6. 页脚

仅展示品牌、产品锚点、支持入口、语言切换和版权；不展示隐私政策链接。

## 响应式与可访问性

- 桌面端使用不对称双栏与交替章节；移动端改为文案在上、完整截图在下；
- 截图不得裁切标题、状态、列表关键数据或底部操作区；
- 设备框使用 CSS 绘制，不在截图外额外添加彩色描边；
- 390px 宽度下无横向滚动，导航可折叠；
- 所有链接和按钮支持键盘焦点；装饰元素不进入无障碍树；
- 语言优先级继续使用 `?lang=zh|en`、localStorage、浏览器语言，并保持锚点位置。

## 技术边界

- 继续使用纯静态 HTML、CSS、原生 JavaScript；
- 重写 `docs/website/index.html` 和首页相关样式；
- 保留 `docs/website/privacy/index.html` 的独立可访问性，但不从首页链接它；
- `site.js` 继续负责语言、导航和 App Store CTA，并增加轻量 IntersectionObserver 入场效果；
- 不增加第三方依赖、Cookie、分析或网络请求。

## 验收标准

- 首页不存在“隐私”“Privacy”“Keychain”“无账号”“云端”等隐私政策叙事或指向 `/privacy/` 的链接；
- 首屏和五个产品章节均使用真实 ConnTerm 截图，不使用伪造控制台或模拟功能数据；
- 中文页面只显示中文截图，英文页面只显示英文截图；
- 1440px、900px 和 390px 视口下无关键内容裁切和横向滚动；
- `/privacy/` 仍可直接访问并正常切换语言；
- 首页、隐私页、CSS、JS、图像资源均返回 200；
- `git diff --check` 通过，页面不请求外部字体、图片、分析脚本或 CDN。
