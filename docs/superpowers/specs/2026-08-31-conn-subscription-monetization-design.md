# Conn 订阅商业化设计

**日期：** 2026-08-31  
**状态：** 已确认，基础实现已完成，待 StoreKit 沙盒与上架配置验收
**范围：** 当前 Conn iOS 版本的免费版、Pro 订阅、付费墙与权益判断

## 1. 当前产品边界

本设计以当前 SwiftUI 工程为事实来源，不继承旧 PRD 中的买断制、iCloud、AI、Widget、Apple Watch 或团队能力假设。

当前 App 已有的核心入口包括：

- 主机列表、分组、健康概览与连接测试；
- SSH 终端、终端会话中心，以及 tmux/Zellij 持久会话能力；
- 命令片段、变量填写、单主机执行、执行历史；
- 主机详情中的进程、文件、Docker、日志模块；
- 密钥管理、应用锁、终端设置、编辑器设置与外观设置。

当前工程已接入 StoreKit 2 和统一付费墙。后续只需完成 App Store Connect 商品配置及沙盒验收，不改变 SSH、监控、日志和安全模块的业务协议。

## 2. 商业化方案

Conn 采用“免费连接与观察，Pro 扩展主机规模并完成高阶运维”的单一订阅模型。

### 免费版

最多保存 2 台主机，包含：

- 主机添加、编辑、删除、分组与健康概览；
- SSH 终端、会话中心和已有持久终端能力；
- 进程查看与结束；
- 日志中心及日志流查看；
- 命令片段、变量填写、单主机执行与执行历史；
- 密钥管理、应用锁、终端设置、编辑器设置和外观设置。

### Conn Pro

Pro 订阅包含：

- 不限主机数量；
- 文件管理：浏览、上传、下载、编辑、移动、复制、删除和权限操作；
- Docker 管理：容器、镜像、卷、网络、Compose，以及已有的启停、重启、删除、日志和控制台能力；
- 多主机批量执行命令片段。

以下能力明确保持免费：

- 日志中心；
- 进程结束；
- 单主机命令执行；
- SSH 终端和基础监控。

## 3. 价格与商品

首发价格：

- 月付：¥18；
- 年付：¥98。

年付相对全年月付 ¥216 节省 ¥118，约为 55% 折扣。年付是 Paywall 默认推荐项，月付作为低承诺入口保留。

StoreKit 商品标识固定为：

- `com.crazyball.conn.pro.monthly`；
- `com.crazyball.conn.pro.yearly`。

两个商品位于同一个自动续费订阅组，首期只设置一个 Pro 等级。产品价格由 App Store Connect 按地区配置；UI 不硬编码本地化货币字符串，而是展示 StoreKit 返回的价格。

首期不实现任何服务端账户、远程收据校验、遥测或自建订阅后台。订阅状态使用 StoreKit 2 的本地签名交易校验和当前权益查询。

## 4. 付费墙触发规则

### 添加第三台主机

免费用户已有 2 台主机时，点击“新增主机”或提交新增表单均不得创建第三台主机，展示 Pro 付费墙。付费墙关闭后保留原表单草稿，购买成功后继续创建流程。

编辑和删除已有主机不受影响。订阅到期后不删除超出 2 台的既有主机；用户仍可访问已有主机，但不能再新增超出免费额度的主机。

### 文件管理

主机详情的“文件”入口保留可发现性，但免费用户点击后立即展示付费墙，不创建 `FileBrowserViewModel` 的远端加载任务。购买成功后继续进入文件页面。

### Docker 管理

主机详情的“Docker”入口保留可发现性，但免费用户点击后立即展示付费墙，不执行 Docker 探测或 SSH 请求。购买成功后继续进入 Docker 页面。

### 批量执行

单主机执行保持免费。`SnippetRunView` 选择多台主机后，用户点击静默执行时展示付费墙；选择多台主机本身不弹窗，允许用户理解该能力，但执行动作必须被拦截。

### 到期与恢复

- 到期后立即回到免费权益；
- 不删除本地主机、凭据、片段、日志或执行历史；
- 允许继续使用免费能力；
- 文件、Docker、批量执行和超额新增主机回到付费墙；
- 启动与回到前台时刷新当前权益；
- 提供“恢复购买”和系统订阅管理入口；
- StoreKit 状态加载期间不执行任何可能误放行的 Pro 操作，界面显示加载态或按免费权限处理。

## 5. Paywall 体验

Paywall 只有一个 Pro 页面：

- 标题：Conn Pro；
- 清楚列出“不限主机、文件管理、Docker 管理、批量执行”；
- 年付默认选中；
- 月付和年付均显示 StoreKit 返回的本地化价格；
- 显示 StoreKit 返回的实际价格与订阅周期；
- 提供购买、恢复购买、隐私说明和订阅管理入口；
- 不使用倒计时、遮挡式启动弹窗或诱导性文案；
- 从具体功能触发时，标题和说明应指出用户当前尝试使用的功能。

所有新增用户可见文案统一经过 `L()`，并补齐 `zh-Hans`、`zh-Hant`、`en`、`ja`、`ko` 五种语言。

## 6. 实现边界

权益判断只有一个出口：`ConnEntitlement` 提供 `isPro`、`canAddHost(currentCount:)` 和 `allowed(_:)`。页面不读取 StoreKit，不自行判断商品 ID，也不复制主机数量规则。

建议拆分为两个层次：

1. `ConnEntitlement` SPM target：放置无 UI、可单测的 Gate、主机额度规则、权益快照、协议和测试替身；
2. App 层 `Monetization`：放置 StoreKit 2 商品加载、交易监听、支付墙 UI、依赖注入和 UI 路由协调。

`ConnEntitlement` 不依赖 ConnOps、ConnTerminal 或 ConnStore，避免商业化层反向侵入远端能力模块。

## 7. 验收标准

- 免费用户最多新增 2 台主机；第三台不会写入数据库；
- 免费用户仍可打开 SSH、进程、日志、命令片段和单主机执行；
- 文件、Docker、批量执行三条路径都会展示 Paywall 且不会先发起远端请求；
- Pro 用户可以继续使用全部现有入口；
- 订阅过期不删除本地数据，且现有免费能力继续可用；
- StoreKit 购买、恢复、交易更新和错误状态均有可测试的替身；
- 新增文案通过五语言字符串覆盖与占位符格式测试；
- 单元测试和当前已启动模拟器上的 XCUITest 均通过。
