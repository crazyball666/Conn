这份政策说明 ConnTerm 如何处理本机数据、远程连接和应用锁。没有隐藏的云端服务，也没有行为分析。

最后更新：2026-08-06 · 适用于 ConnTerm iOS 应用

范围数据处理网络连接安全与 Keychain儿童隐私联系与更新

1. 范围

ConnTerm 是一款本地 SSH 服务器运维工具。我们不要求注册账号，也不运营 ConnTerm 云服务。本政策适用于 ConnTerm iOS 应用及其本机功能。

2. 我们处理的数据

ConnTerm 的核心数据留在你的设备上：

  • 你添加的主机配置、脚本、操作记录和密钥元数据。
  • 监控数据只在应用使用期间用于展示，不提供后台告警推送。
  • ConnTerm 不使用广告、跨 App 跟踪或第三方分析 SDK，也不会把上述数据上传到 ConnTerm 服务器。

3. 网络连接

ConnTerm 仅连接你主动添加的 SSH 主机以及你在应用中明确配置的目标。远程命令、文件和 Docker 操作由你发起并承担相应风险。请只连接你拥有或获授权访问的主机。

本地网络权限仅用于发现或连接你配置的目标，不用于广告或跟踪。

4. 安全、Keychain 与应用锁

  • 私钥保存在 Apple Keychain 中；ConnTerm 不会把私钥或主机配置上传到 ConnTerm 服务器。
  • 如果你启用应用锁，ConnTerm 会使用设备密码或 Face ID/Touch ID 在本机验证身份，认证结果不会离开设备。
  • 危险命令和 Docker 操作会在执行前要求确认，但 ConnTerm 不替你判断业务影响。

5. 儿童隐私

ConnTerm 面向开发者和系统管理员，不针对儿童设计。我们不要求注册账号，也不主动收集、上传或出售任何个人信息。未成年人使用本应用时，应在监护人同意和指导下连接其有权访问的主机。

6. 联系与政策更新

如需报告隐私问题，请通过项目仓库提交 issue。我们会在本页更新政策变更，并在应用发布说明中提示重大变化。
